# Hotelier - Hotel Reservation System (HTML, CSS, JS only)

Files: index.html, style.css, script.js, images/

## Run
Double-click index.html (or use VS Code Live Server).

## Deploy (no build step)
- Netlify: drag the hotelier folder onto app.netlify.com/drop
- Vercel: `vercel` inside the folder, or import the repo
- GitHub Pages: push the folder contents, then Settings > Pages > Deploy from branch

Notes: bookings, saved rooms and admin data live in the browser's localStorage (demo only: no real payments, login or server). Voice input works in Chrome/Edge. Fonts load from Google Fonts when online.
