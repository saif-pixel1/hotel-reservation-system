
`index.html` loads `style.css` and `script.js`. The Google Fonts request for
**Bodoni Moda** and **Figtree** is in the `<head>`.

---

## Running it

1. Keep `index.html`, `style.css`, `script.js`, and the `images/` folder
   together.
2. Open `index.html` in a browser.

That's it. To serve locally with a nicer URL:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
